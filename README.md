# Алиас

Локальная игра в Алиас с личным счётом. Svelte 5 + TypeScript + Vite. Статическая PWA: без игрового сервера, аккаунтов, аналитики и внешних шрифтов.

**[Играть](https://moitimemasters.github.io/alias-local/)**

## Правила

- Играют от 2 до 12 человек на одном устройстве. Объясняющий меняется каждый ход.
- Угадавшему **+1**, объясняющему **+0,5**. За пропуск объясняющему **−1**. Отрицательный счёт допустим.
- Цель: 30, 60 или 100 личных очков. Ход: 30, 60, 90 или 120 секунд.
- Нажатие на имя засчитывает ответ. Свайп вверх открывает выбор угадавшего (при двух игроках засчитывает сразу), вниз пропускает слово.
- Во время касаний, нажатий клавиш и открытых диалогов таймер остановлен. Отдельная пауза скрывает слово.
- По истечении времени текущее слово доигрывается без таймера. Отмена возвращает слово и снимает оба начисления.
- Слова не повторяются в пределах партии.

## Установка и офлайн

Первый раз откройте страницу с интернетом: service worker сохранит интерфейс, иконки и **все четыре словаря**. Последующие запуски и игра работают без сети. Chrome/Edge/Android предлагают установить приложение; в Safari на iPhone используйте «Поделиться» → «На экран “Домой”».

Отключение сети до завершения первого кэширования ещё не даст полноценного офлайн-режима. Service worker требует HTTPS или localhost — открывать `dist/index.html` через `file://` нельзя. GitHub Pages лишь раздаёт статические файлы; после загрузки игровой сервер не нужен.

Партия и настройки хранятся в `localStorage` этого браузера: игроки, очки, колода, слово, оставшееся время и история отмены. На уходе в меню, скрытии страницы и закрытии время фиксируется на паузе. Сохранённая игра открывается через «Продолжить игру». Если очистить данные сайта, сохранение удалится. Синхронизации между устройствами нет.

Обновление PWA применяется по кнопке, сохранив игру перед перезагрузкой. Прежние web-сохранения Alias 1.x мигрируют при доступности на том же origin; данные APK и другого сайта браузеру недоступны.

## Разработка

Node.js **24**; зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
npm run verify
npm run preview
```

- `npm run format` / `format:check`: единый стиль Prettier с поддержкой Svelte.
- `npm run lint`: официальные recommended-правила Svelte и TypeScript с проверкой типов; ноль предупреждений.
- `npm run check`: строгая проверка TypeScript и компонентов Svelte.
- `npm test`: правила, отмена, победа, часы, сохранение/миграция и словари.
- `npm run build`: статические файлы в `dist/`, manifest и service worker.
- `BASE_PATH=/alias-local/ npm run build`: сборка для GitHub Pages. На корневом домене не задавайте `BASE_PATH`.

## Структура

- `src/lib/game.ts`: типизированные данные и чистый reducer. Очки хранятся целыми полубаллами: нет ошибок округления. Время передаётся в reducer явно, без зависимости от браузера.
- `src/lib/config.ts`: настройки и единая проверка допустимых игроков, словарей, времени и цели.
- `src/lib/presentation.ts`: представление счёта, таймера и журнала, отдельно от правил.
- `src/lib/clock.ts`: монотонные часы и набор перекрывающихся блокировок UI. Освобождение одного касания не снимает паузу открытого диалога.
- `src/lib/controller.svelte.ts`: реактивный контроллер Svelte 5, lifecycle, сохранение и orchestration. Immutable игровое состояние использует `$state.raw`, редактируемые настройки — `$state`.
- `src/lib/interaction-events.ts`: физические касания/клавиши, отложенное освобождение после native click и cleanup. Фон не снимает блокировку открытого диалога.
- `src/lib/word-gesture.ts`: одна завершённая вертикальная gesture, отмена и подавление её compatibility click; обычный tap и клавиатура остаются доступны.
- `src/lib/persistence.ts`: версионированное сохранение, проверка структуры и миграция 1.x. Старым ответам не добавляется выдуманный бонус, поэтому отмена корректна после обновления.
- `src/components/`: отдельно настройка, ход, результаты, счёт и доступные нативные диалоги. Нажатия используют обычный `click`, без повторной активации на `pointerup`.
- `src/lib/webmcp.ts`: опциональные инструменты браузера для агента (`read_alias_game`, `new_alias_game`, `play_alias`). Агент может играть и проверять счёт/паузы, но приложению агент не нужен. Пауза скрывает слово и в этих инструментах.
- `vite.config.ts`: Workbox precache; все ресурсы приложения локальные.

Новая архитектура намеренно не содержит SSR, API, БД на сервере или дополнительного глобального менеджера состояния. Для этой игры достаточно Svelte-компонентов, контроллера и чистых функций.

## Проверка интерфейса

При изменениях проверьте в реальном браузере: одинарное нажатие паузы/продолжения; полное нажатие строки игрока; оба свайпа; остановку времени в выборе игрока и правилах; последнее слово; отмену; восстановление после перезагрузки; офлайн-запуск. Проверьте ширины 320, 390, 768 и 1280 px и горизонтальную ориентацию.

GitHub Actions запускает типы, тесты и production-сборку, затем публикует `dist/` в Pages. Проверки pull request ничего не разворачивают. Браузерные проверки вручную дополняют доменные тесты; автоматические тесты не подтверждают установку PWA на физических iOS/Android-устройствах.

Первичные рекомендации: [frontend-practices.md](docs/frontend-practices.md). Результаты цикла ревью → исправление → проверка: [review-log.md](docs/review-log.md).

## Словари и происхождение

Источник: [Roman-/dicts](https://github.com/Roman-/dicts). Лёгкий: 2049 слов; Оптимус: 3106; Мозговой штурм: 2410. «Новые сложные»: 12700 слов из `rus_custom_15kfun.txt`, длина 5–26; исключены совпадения с Мозговым штурмом после приведения к нижнему регистру и замены ё на е. Полные метаданные — `public/dictionary-sources.json`.

Приложение не связано с разработчиками настольного Alias или orange Alias. Словари перенесены из прежней локальной версии игры; у upstream не обнаружено отдельного файла лицензии. Лицензия MIT ниже относится **к нашему коду**, не переоформляет права на сторонние наборы слов. Для распространения словарей сохраняйте происхождение и проверяйте условия у их авторов.
